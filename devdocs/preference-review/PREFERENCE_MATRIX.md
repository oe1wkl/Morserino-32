## 2. Which preferences each mode offers

Column key:

- **Keyer** — CW Keyer (`keyerOptions`)
- **Gen** — CW Generator (Random, Abbrevs, Words, Calls, Mixed, Practice Set) (`generatorOptions`)
- **GenFile** — CW Generator: File Player (`playerOptions`)
- **Echo** — Echo Trainer (Random ... Practice Set) (`echoTrainerOptions`)
- **EchoFile** — Echo Trainer: File Player (`echoPlayerOptions`)
- **KochGen** — Koch Trainer: CW Generator (`kochGenOptions`)
- **KochEcho** — Koch Trainer: Select Lesson, Learn New Chr, Preview Char, Echo Trainer, Adaptive (`kochEchoOptions`)
- **LoRa** — LoRa Trx (`loraTrxOptions`)
- **WiFi** — WiFi Trx (`wifiTrxOptions`)
- **ExtTrx** — iCW/Ext Trx (`extTrxOptions`)
- **RKeyer** — Remote Keyer (`kipKeyerOptions`)
- **RRig** — Remote Rig (tools only; no prefs gesture in the mode) (`kipRigOptions`)
- **Bot** — QSO Bot (`qsoBotOptions`)
- **Decoder** — CW Decoder (`decoderOptions`)

A number = offered, at that position in the mode's list. `C` / `A` after a cell = differs on the Classic /
a11y build (`C—` not offered there, `C+` offered only there). Rows in All-view order; preferences no mode
offers are listed after the table.
