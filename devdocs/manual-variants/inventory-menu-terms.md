Generated by `make_inventories.py`. Do not edit by hand.

with the build flags that gate it and the lines of each manual where the
string occurs. **Nothing here is changed yet** -- session 2 introduces the
placeholder mechanism that resolves these from a per-variant terminology
file; this is the list it has to cover.

The variant column comes from the firmware's own `#ifdef`s, not from the
prose, so it is the authority when the two disagree.

the case a naive label-only terminology file would miss.

- on classic (`!LORA_DISABLED`): `Tx OFF`, `WiFi Tx ON`, `LoRa Tx ON`
