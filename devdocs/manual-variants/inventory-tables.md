## Other screen-reader notes

- Pandoc emits `<th>` for the header row but **without a `scope`
  attribute**; the briefing's session-2 list already has scoped `<th>`
  on it, and it applies to all 57 tables.
- Several description cells carry a literal `<br>` to force a line break
  inside the cell. That is fine visually and harmless to a screen reader,
  but it means cell text is not always one flowing sentence.
- The preference tables now carry row markers (an empty variant span at
  the start of the first cell). A filter that drops those rows must drop
  the whole `Row`, not just the span.
