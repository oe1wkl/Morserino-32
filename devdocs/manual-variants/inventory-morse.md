# Inventory: Morse written as symbols

Generated by `make_inventories.py`. Do not edit by hand.

Session 2 wraps these in a `.morse` span so the a11y build can emit a
spoken dit/dah form alongside the visual symbols. The result of actually
counting them is the headline: **there are two sites per language, in two
different notations.** This is a much smaller job than the briefing
anticipated.

## How these were found

A Morse token is a run of 2 to 8 element characters, bounded by
non-word characters, that contains **at least one dit and at least one
dah**. Requiring both is what separates real Morse from the look-alikes
in this document: the ellipsis in `n is 1 .. 8`, the `---` of a table
rule, and the escaped filename `*m32\_Vx.y\[\...\].bin*` are all
single-element runs and drop out. Before matching, `\.` is normalised to
`.` and `\_` / `_` to `-`, so both notations are searched with one
pattern.

## Related notations found on the way

**Prosigns in angle brackets** -- `<ka>`, `<sk>`, `<as>`, `<bk>`, `<err>`,
`\<HH>`: 41 occurrences in EN, 41 in DE. Not Morse symbols, but the other
notation a screen reader will mangle -- verified that pandoc escapes them
to `&lt;ka&gt;`, so they survive into the HTML intact; how a screen reader
pronounces them is a session-2 question. The firmware already has an
answer for the spoken form: the voice engine says "pro sign" followed by
the two NATO letters (see `extract_voice_strings.py`), which is the
obvious model to copy.

**`dit` / `dah` spelled out in prose** -- 39 lines in EN, 40 in DE. This
is the form the a11y build wants to emit for the symbol sites above, so
the vocabulary is already established in the text.

## Recommendation

With only two sites, wrapping them by hand in session 2 is trivial. The
thing worth deciding is the *notation* going forward: the manual uses dot
+ underscore in one place and dot + hyphen in the other, for no visible
reason. Picking one (dot + hyphen reads better and needs no backslash
escaping) would be a one-line change and makes any future `.morse` filter
a single pattern instead of two.
